GALAXY LOVE 2.0 - NETLIFY READY

Deploy:
1. Extract this ZIP.
2. Open Netlify -> Add new site -> Deploy manually (or drag-and-drop deploy).
3. Drag the CONTENTS of this folder (index.html, JS/CSS files, and assets folder) into the deploy area.
4. Do not upload only index.html. Keep the assets folder beside index.html.

Music:
- index.html references assets/love-song.mp3
- The supplied soundtrack has been copied and renamed to that exact path.

Required root files:
- index.html
- styles.css
- script.js
- galaxy3d.js
- photo-assets.js
- assets/love-song.mp3

Keep photo-assets.js before script.js and galaxy3d.js in index.html.
